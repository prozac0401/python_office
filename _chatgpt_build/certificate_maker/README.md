# CertificateMaker v1.1

Win32 COM 기반 인증서 자동 제작 도구입니다.

- PowerPoint 템플릿의 `{이름}`, `{과정명}` 등 변수를 Excel 첫 번째 시트 데이터로 치환
- 출력 파일명 변수 치환
- PPTX / PDF / PNG 출력
- PNG 너비/높이 슬라이더(400~5000px)
- PNG 비율 고정 옵션
- PowerPoint 창 표시 기본 OFF
- 동일 파일명 자동 회피
- 세로형 담백한 인증서 샘플과 예제 XLSX 포함
- 샘플 발급기관: 첨단기술아카데미

Windows + Microsoft PowerPoint가 필요합니다.
